# Schnellerfassung – was Tagwerk versteht

Tipp auf **+** (auf „Heute“ oben links oder im Planer oben rechts) und schreib einfach einen Satz.
Was Tagwerk erkennt, erscheint als farbiger Chip unter dem Textfeld. Der Rest wird der Titel.

| Du schreibst | Ergebnis |
|---|---|
| `morgen 10 uhr zahnarzt` | „Zahnarzt“, morgen 10:00 |
| `Zahnarzt morgen um 10:30` | „Zahnarzt“, morgen 10:30 |
| `heute abend joggen` | heute 19:00 |
| `morgen früh laufen` | morgen 8:00 |
| `18 uhr meeting` | heute 18:00 (ist 18 Uhr vorbei: morgen) |
| `am freitag steuer` / `bis freitag bericht` | nächster Freitag, ganztägig |
| `nächsten montag wäsche` | Montag nächster Woche |
| `nächste woche planung` | Montag nächster Woche |
| `wochenende ausflug` | kommender Samstag |
| `24.12. geschenke` / `24.12.2027 …` | an diesem Datum |
| `am 1. miete` | nächster Monatserster |
| `in 2 stunden wäsche` / `in 30 min tee` | genau dann, mit Uhrzeit |
| `in 3 tagen rezept holen` | in drei Tagen, ganztägig |
| `jeden montag müll rausbringen` | wöchentlich am Montag |
| `jeden di und do gym` | wöchentlich Di + Do |
| `mittwochs schwimmen` | wöchentlich am Mittwoch |
| `täglich 8 uhr tabletten` | täglich 8:00 |
| `werktags 7:30 stand-up` | Mo–Fr 7:30 |
| `alle 2 wochen bettwäsche` | alle 2 Wochen |
| `monatlich am 1. miete zahlen` | monatlich am 1. |
| `jedes jahr steuererklärung` | jährlich |
| `!` / `!!` / `!!!` | Priorität niedrig / mittel / hoch |
| `#Arbeit` | in die Liste „Arbeit“ (wird bei Bedarf angelegt) |

**Hinweise**
- Uhrzeiten: `10 uhr`, `um 10`, `10:30`, `18.30 uhr`, `14h`.
- Tageszeiten: `morgens` 8:00, `vormittags` 10:00, `mittags` 12:00, `nachmittags` 15:00, `abends` 19:00, `nachts` 22:00.
- Wochentags-Abkürzungen (`mo`, `di`, …) zählen nur mit Punkt (`do.`) oder nach `am`, `jeden`, `nächsten` –
  sonst würde aus „so geht das“ ein Sonntag.
- Mit Uhrzeit erscheint der Schalter **„Als Termin in den Kalender“**: Dann wird statt einer Aufgabe ein
  einstündiger Kalendertermin angelegt.
- **„Mit Details anlegen“** legt die Aufgabe an und öffnet direkt den Editor (Notizen, Unteraufgaben, Erinnerung …).

Das Gleiche funktioniert per Siri: „**Neue Aufgabe in Tagwerk**“ und dann den Satz sagen.
